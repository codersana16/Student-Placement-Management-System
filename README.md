# Student Placement Management System

A console-based Student Placement Management System developed using Core Java, JDBC, and MySQL.

## Features

- User Login Authentication
- Add Student
- View Students
- Search Student by ID
- Search Student by Name
- Update Placement Details
- Delete Student
- Dashboard
- View Placed Students
- View Unplaced Students
- View Students by Company
- Sort Students by CGPA
- Placement Percentage
- Highest Package Student
- Lowest Package Student
- Search Students by CGPA
- Export Student Report to CSV

## Technologies Used

- Core Java
- JDBC
- MySQL
- IntelliJ IDEA
- Git
- GitHub

## Database
